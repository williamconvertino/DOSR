Weekly DEMO Goals

* Overall goal is to have a basic demo of the client when creating a new repo, making a new PR, and requesting/recieving approval from server

* Can launch a client application (just one for now, will add multi-client demos and P2P later)
* Can launch a DOSR server (for now all on one device, for easier networking setup)
* Client application has basic gui and well-formatted CLI tools for all the following (keep code organized so it can be updated later)
* Client can create new repo and specify initial configuration settings
* Client can edit code and track changes with GIT
* Client can submit changes to DOSR app
* App bundles changes and relevant additional files according to project config
* App generates formatted PR according to project config
* App sends PR to DOSR server
* DOSR server responds with either approval or rejection
* CLI/GUI conveniently displays the progress of the PR submission (like whether its building git commit, building PR, sending to server, waiting for reply, etc., as well as elapsed/remaining time estimate, etc.)
* Final approval decision is also displayed, along with latency of each step and any errors
