        PR template
        
      
        A PR template decides what is collected from Git, what the reviewer is told, and how the PR is laid out. It is a TOML file; a repository embeds its template in the immutable policy, so editing a file later never changes existing repositories.
        
      
        
        
        
        
      
        
      
        Read-only: built-in and in-use templates never change. Use Copy into editor to make your own version.

        P2P sharing
        
      
        Repositories travel between devices over IPFS as a git bundle plus the signed attestation for every accepted PR. A share code (an IPFS CID) points at one published state. Importing it re-checks the bundle and every signature before your copy moves. (Dev stand-in for the chain: until the contract exists, share codes are passed by hand or through the peer inbox.)
